# NotFar Manager

Портативный файловый менеджер для Windows 10 и 11 x64. [Скачать EXE](https://github.com/matedwq/NotFar-Manager/releases/latest)

## Работа с файлами

1. Выберите диск или введите путь в одну из панелей и нажмите **Enter**. Двойной щелчок открывает папку. **Backspace** или кнопка со стрелкой поднимает на один уровень. **Tab** переключает панели.
2. Щёлкните заголовок **Имя**, **Тип** или **Размер**. Повторный щелчок меняет направление сортировки. **F5** перечитывает каталог.
3. Выделяйте файлы правой кнопкой мыши, **Ctrl+щелчком**, **Insert** или **Пробелом**. **Shift+щелчок** выделяет диапазон. **Ctrl+A** выделяет все файлы активной панели. Выделенные строки отображаются красным.
4. Кнопка **Выделить файлы меньше** заменяет текущее выделение файлами строго меньше указанного размера. Начальное значение — **2048 байт**. **Снять выделение** очищает выбор. **Удалить выделенное** запрашивает подтверждение и удаляет файлы без корзины.

Вызовите **Ctrl+M** для выделенных файлов. Маска **[C]** подставляет счётчик, **[N]** — исходное имя, **[E]** — исходное расширение. Маски могут также включать обычный текст. Счётчик следует порядку строк в панели. При начале 1, шаге 1 и ширине 8 получаются имена вида `00000001.png`. Восемь — минимальное число цифр, включая ведущие нули. Для обратного счёта укажите отрицательный шаг. После **Выполнить** программа проверяет новые имена, показывает ход работы и закрывает окно по завершении. Имена других файлов защищены от перезаписи.

При остановке пакетной операции уже выполненные изменения сохраняются. Панель перечитывает каталог после изменений. Программа показывает число выполненных операций и ошибок.

EXE можно запускать с одним или двумя начальными путями, например `NotFar-Manager.exe "D:\Данные" "C:\"`.

## Сборка

Запустите `build.cmd` в Windows с Visual Studio Build Tools 2022 или новее и компонентом «Разработка классических приложений на C++». Результат — `build\NotFar-Manager.exe`. Команда `build.cmd test` также прогоняет проверки на временных каталогах. Команда `build\files-test.exe --scan "D:\Тестовый каталог" 200000` измеряет чтение и сортировку уже созданного каталога с указанным количеством файлов. Команда `build\files-test.exe --benchmark 200000` создаёт временный каталог, выполняет тот же замер и удаляет тестовые файлы.

NotFar написан на C++20 и Win32. Перечисление каталога читает пакеты записей через `GetFileInformationByHandleEx` с резервным путём через `FindFirstFileExW`. Имя, размер и признак папки берутся из записи каталога. Сортировка, чтение и операции с файлами работают в фоновых потоках. Виртуальные списки запрашивают текст видимых строк. Использован тот же подход пакетного чтения, что и в [Far Manager](https://github.com/FarGroup/FarManager), с отдельной реализацией на документированном Win32 API.
